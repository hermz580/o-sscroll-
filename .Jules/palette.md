## 2026-05-24 - [Two-Step Deletion with Auto-Reset]
**Learning:** In a fast-paced or mystical-themed UI, immediate destructive actions can break flow and cause anxiety. A two-step confirmation (Trash -> Check) integrated into the item itself preserves the aesthetic while providing safety. Using `onMouseLeave` to reset the confirmation state allows for effortless "cancellation" without needing a dedicated cancel button.
**Action:** Use this pattern for secondary destructive actions in sidebars or lists where a full modal would be too disruptive.
